🔐 Authenticate to vCenter

Your credentials authenticate directly to vCenter for all operations. A session token is held in memory for this browser session only — credentials are never stored on disk or in the database.
Jobs run under these credentials. The username will appear in all audit log entries and job records.

⚙️ VM Shutdown / Power-On Order

Drag to reorder. Shutdown: top → bottom (DC last). Power-On: bottom → top (DC first). 120s delay between each VM on power-on.

Site:

    VM order is saved to SQL — changes take effect on next job execution.

    ⚠️ Cancel Scheduled Job

    This will permanently cancel the scheduled job. No hosts will be patched and no change will be made to vCenter.
    The cancellation reason will be recorded in the audit log.
